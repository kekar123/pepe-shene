## 🚀 Возможности

- 📝 **Редактирование текстовых полей** - название, состав, способ применения и др.
- 📏 **Точные размеры в миллиметрах** - поддержка формата 58×60 мм и других
- 🖱️ **Интерактивный холст** - перетаскивание элементов мышкой
- 📐 **Изменение размеров** - через уголок элемента
- 🔍 **Масштабирование** - Ctrl + колесо мыши
- 🖼️ **Экспорт в PNG** - высокое разрешение (300 DPI)
- 💾 **Сохранение в JSON** - для последующего редактирования
- 📂 **Загрузка JSON** - поддержка формата ARTDECO/Kerasis
- 🎨 **Предпросмотр в реальном времени**
- ⌨️ **Горячие клавиши** - пробел для перемещения по холсту

## 📋 Требования

- **Python 3.7** или выше
- **Пакеты Python**: Flask, Flask-CORS
- **Современный браузер** (Chrome, Firefox, Edge)

## 🔧 Установка и запуск

## Установка

### 1. Установка Python
- Скачайте Python 3.7 или выше с [официального сайта](https://www.python.org/downloads/)
- При установке отметьте галочку "Add Python to PATH"
- Проверьте установку: `python --version`

### 2. Скачивание нужных компонентов 

pip install flask flask-cors

или так 

pip install -r requirements.txt
