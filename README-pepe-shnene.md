# SKLAD: Схема Склада и Общий Отчет

Этот документ описывает две страницы проекта:
- `Склад` (`/warehouse`)
- `Общий отчет` (`/combined`)

## 1) Страница "Склад" (`/warehouse`)

### Назначение
Показывает фиксированную схему аллей/ячеек и окрашивает ячейки по цвету стока из загруженного общего отчета.

### Где находится
- Шаблон: `templates/warehouse.html`
- Скрипт: `static/js/warehouse.js`
- Стили: `static/css/style.css`
- Роут страницы: `app.py` -> `@app.route('/warehouse')`

### Как работает сейчас
1. Схема аллей фиксированная (748..742).
2. Пользователь загружает файл общего отчета (`.xls/.xlsx`) в форме на странице.
3. Файл отправляется в API:
   - `POST /api/warehouse-layout-from-report`
4. Из отчета берутся:
   - `Аллея пикинг`
   - `Место пикинг`
   - `Мертвый сток`
5. Схема не перестраивается по новым аллеям; перекрашиваются только существующие ячейки.

### Правила окраски
- `красный` -> красная ячейка
- `желтый` -> желтая ячейка
- `зеленый` -> зеленая ячейка
- `Проход (21-24)` имеет отдельный стиль и не перекрашивается цветом стока.

## 2) Страница "Общий отчет" (`/combined`)

### Назначение
Загрузка набора Excel-источников и формирование объединенного отчета с таблицей и выгрузкой файла.

### Где находится
- Шаблон: `templates/combined.html`
- Скрипт: `static/js/script.js`
- Стили: `static/css/style.css`
- Роут страницы: `app.py` -> `@app.route('/combined')`

### Как работает сейчас
1. Страница принимает 6 файлов:
   - Основные данные (`master_file`)
   - Движения стока (`movements_file`)
   - Линии пикинга (`lines_file`)
   - ABC анализ (`abc_file`)
   - Проверка заказано-собрано (`order_picked_file`)
   - PUD отчет по стоку (`stock_file`)
2. Файлы отправляются в API:
   - `POST /upload-combined`
3. На сервере вызывается генератор:
   - `generate_combined_report(...)`
4. Возвращается:
   - `rows` (данные таблицы)
   - `report_file` (имя сформированного Excel)
5. Скачивание результата:
   - `GET /download-report/<filename>`

### Ключевые поля в готовом отчете
- `Аллея пикинг`
- `Место пикинг`
- `Мертвый сток`

Эти поля используются также на странице `Склад` для окраски ячеек.

## 3) API, связанные с этими страницами

- `POST /upload-combined`  
  Формирование общего отчета из 6 входных файлов.

- `GET /download-report/<filename>`  
  Скачивание сформированного общего отчета.

- `POST /api/warehouse-layout-from-report`  
  Разбор загруженного общего отчета для схемы склада (цвета и валидные пары аллея/место).

## 4) Быстрый запуск

Из корня `pepe-parser`:
- `app.py`

Приложение поднимается на Flask-сервере, после чего страницы доступны по маршрутам:
- `/combined`
- `/warehouse`
